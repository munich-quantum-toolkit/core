MQSF 2026
System Software for Quantum Computing: From the Metal to the User
Lukas Burgholzer

PRESENT THE TALK

1. Extract this ZIP to a local folder.
2. Open index.html in Chrome, Edge, or Firefox. No installation, server,
   or internet connection is needed to play the presentation.
3. Press F for fullscreen. Use the clicker's forward/backward buttons.

Forward advances to the next build or slide. Animations finish and hold.
Pressing forward during an animation finishes it and advances immediately.
Rehearse this behavior with the actual laptop and clicker before the talk.

CONTROLS

Next                  Right / Page Down / Space / Enter
Previous              Left / Page Up / Backspace
First / last slide    Home / End
Jump to a slide       Type its number, then Enter
Slide overview        G or Escape; arrows to select, Enter to open
Fullscreen            F
Blackout              B
