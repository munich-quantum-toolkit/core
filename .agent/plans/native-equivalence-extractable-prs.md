# Extractable Core changes

These are review boundaries for the native verification implementation, plus
defects identified while implementing it. No PRs have been published.

| Candidate                           | Scope and reason                                                                                                                                                                                                                                 | Dependency / state                                                                                                                                                                                                                                 |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Per-package DD resource control     | `dd/ResourceControl`, allocator-aware slabs/tables/root maps, recursive cancellation and deadline checks. Makes simultaneous packages share an explicit byte budget without changing numerical settings.                                         | Independent; implemented. 220 DD tests pass, including five new cancellation/allocation tests.                                                                                                                                                     |
| Shared worker grants                | `DDWorkerBudget` and existing sampling scheduler. Cancellable acquisition waits for one slot, then takes only available extra slots; sampling retains its behavior.                                                                              | Independent runtime refactor; implemented and queue cancellation tested.                                                                                                                                                                           |
| Bounded execution recording         | `DDFunctionality`: resolve concrete SCF/calls through the existing interpreter into immutable gates, roots, and terminal output tokens. Adds total steps, call-depth, payload, qubit, and gate bounds without changing existing simulation APIs. | Existing interpreter; implemented. All 109 previous runtime tests and 10 new tests pass.                                                                                                                                                           |
| Deferred CBit load correctness      | `loadRegister`: preserve a measurement token when a load is copied to another returned register; clear a stale token after a later concrete overwrite.                                                                                           | Small runtime fix required by execution recording; copy/overwrite regression tests added.                                                                                                                                                          |
| Classical allocation overflow guard | Check CBit payload count before multiplying its width by element size. A near-`INT64_MAX` width must fail before allocation.                                                                                                                     | Part of bounded recording; implemented and tested.                                                                                                                                                                                                 |
| Shared verification interface       | `VerificationInterface`: decode source tags and initial/routing/site maps; preserve output result/name/bit identity; expose clean-output obligations.                                                                                            | Resolved trace; implemented. Independent of checker algorithms.                                                                                                                                                                                    |
| Native checker API                  | Construction, alternating, simulation; coherent and exact terminal-effect relations; aggregate results and evidence; borrowed C++/Python APIs.                                                                                                   | Above components; implemented with native, Python, independent dense, and QCEC differential validation.                                                                                                                                            |
| Preliminary oracle deletion         | Replace `ExactUnitaryTest.h`, its CMake target, and all 53 callers with a thin native construction assertion. Preserve existing phase, per-entry tolerances, and independent matrix references.                                                  | Native construction; implemented. Synthesis fixtures declare previously implicit wire identities; physical-only pipeline fixtures preserve a literal identity fixed before compilation.                                                            |
| Raw physical input provenance       | Target compilation accepts already-physical `qco.static` inputs and bypasses placement/routing without recording a layout. Native verification correctly requires an explicit shared physical identity.                                          | Deferred producer API change. Three migrated physical-only fixtures supply their predeclared literal identity to both sides and assert the compiler produced no layout before adding it; logical/front-end compilation already records provenance. |
| Package-local numerical settings    | Legacy `dd::RealNumber::eps` is process-global. Separate packages cannot safely change it concurrently. The verifier never changes it and documents external-setter exclusion.                                                                   | Deferred separate design; needs canonical-table and legacy-caller audit, not a new verifier option.                                                                                                                                                |
| Identity-check root semantics       | The investigation found `isCloseToIdentity` can accept a zero or phase-scaled root because it tests shape below the root. The new verifier uses weighted residuals.                                                                              | Deferred independent API/caller audit before changing established helper semantics.                                                                                                                                                                |
| Powered-matrix numerical invariant  | A dense unitary accepted within the IR tolerance can become grossly nonunitary or non-finite after a large power. Resolved execution validates the resulting matrix before DD replay.                                                            | Verifier boundary fix implemented with regressions; a separate audit should decide the shared `PowOp::getUnitaryMatrix` contract and diagnostics.                                                                                                  |
| Local C++ lint result collection    | The pinned cpp-linter local client omits the GitHub output file that nox reads unconditionally. Make local result collection explicit or update the upstream client.                                                                             | Deferred tooling fix. Validation used a venv-only adapter that writes the client's actual findings count; no repository lint policy changed.                                                                                                       |

DD byte accounting excludes allocator overhead and process RSS. Trace payload
accounting excludes MLIR-interned attributes and interpreter dictionaries; the
step limit bounds their execution growth. These explicit limits do not justify
claiming hard memory isolation or hard real-time cancellation.
